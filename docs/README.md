## 维护原则

- 一项规则只在所属文档定义；其他页面保留必要摘要和链接。
- 文档保留稳定行为、使用步骤和设计理由。参数、阈值和拒绝用例详表链接到源码或测试。
- 机器快照、性能数字和执行日志放入对应运行或发布证据，不写成长期说明。
- 行为变化更新技术规格与变更记录，需要消费者采取动作时再更新升级指南。
- 优先修改现有主题文档，不为单次任务新增长期页面。
